- `interface RateHttpClient { public function get(string $url): HttpResult; }`
- `final readonly class HttpResult { __construct(public int $status, public string $body) }`
- `final class CurlRateHttpClient implements RateHttpClient`: `get()` volá `service('curlrequest', ['timeout' => 3, 'connect_timeout' => 2, 'http_errors' => false, 'headers' => ['Accept' => 'application/json, text/csv, text/plain']], false)`; `Throwable` (sieť, timeout, DNS) → `RateUnavailable('http_error')` bez tela odpovede v správe.
- `interface RateProvider { source(): string; homeCurrency(): string; direction(): string; latestOnOrBefore(string $currency, string $bound): RateQuote; }`
- `NbpRateProvider` (source 'NBP', home 'PLN', 'multiply'), `EcbRateProvider` ('ECB', 'EUR', 'divide'), `CnbRateProvider` ('CNB', 'CZK', 'multiply'); konštruktor `__construct(RateHttpClient $http)`.
- `final class RateProviders`: `static for(string $source, RateHttpClient $http): RateProvider` (neznámy zdroj → `InvalidArgumentException`); `const HOME = ['NBP' => 'PLN', 'ECB' => 'EUR', 'CNB' => 'CZK']` (dátový fakt o API, nie nastavenie, RESEARCH Pattern 3).
- `final class RateNotFound extends RuntimeException` (žiadny kurz pre menu/rozsah), `final class RateUnavailable extends RuntimeException` (`public readonly string $reason`: 'http_error'|'http_status'|'parse_error').

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| server → externé API (NBP, ECB, ČNB) | odchádzajúce HTTPS volania, nedôveryhodné odpovede |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-08 | Spoofing/Tampering (SSRF) | zostavenie URL v provideroch | mitigate | hostiteľské mená sú konštanty v kóde; do URL ide iba kód `^[A-Z]{3}$` a dátum `Y-m-d` z DateTimeImmutable; žiadna URL z používateľského vstupu |
| T-08-09 | Denial of Service | pomalé alebo visiace API | mitigate | CURLRequest `timeout` 3 s, `connect_timeout` 2 s; Throwable → RateUnavailable (negatívna cache v 08-04) |
| T-08-10 | Tampering | parsovanie odpovede (JSON/CSV/TXT) | mitigate | `JSON_THROW_ON_ERROR`, hĺbka 16, RateQuote validuje regex kurzu a dátumu; neplatná odpoveď = RateUnavailable('parse_error'), nikdy nevalidný kurz |
| T-08-11 | Information Disclosure | výnimky a logy | mitigate | výnimky nesú iba reason a HTTP status, nie telo odpovede ani hlavičky |
| T-08-12 | Tampering (MITM) | HTTPS spojenie | mitigate | iba `https://` URL, CURLRequest s predvoleným overením certifikátu (`verify` nezakazovať) |
</threat_model>
