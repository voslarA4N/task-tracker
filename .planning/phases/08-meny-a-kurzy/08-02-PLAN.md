Existujúce: `Money::of(string)` (regex `^-?\d{1,10}(\.\d{1,2})?$`, `MAX = '9999999999.99'`, `OverflowException`), `bcround(..., RoundingMode::HalfAwayFromZero)` (PHP 8.4+, len v kontajneri), `PdfFormat::date(string $ymd, string $language)`.

Nové (namespace `App\Libraries\Fx`):
- `final readonly class RateQuote`: `__construct(string $source, string $currency, string $rate, int $amount, string $validFor, ?string $tableNo, string $direction)`; `source` ∈ {'NBP','ECB','CNB'}; `currency` = cudzia mena (`^[A-Z]{3}$`); `rate` = publikovaný reťazec `^\d{1,10}(\.\d{1,8})?$` a > 0 (kontrola `bccomp`); `amount` ≥ 1; `validFor` `Y-m-d`; `direction` ∈ {'multiply','divide'}. Neplatné → `InvalidArgumentException`.
- `final readonly class FxQuote`: polia `source` ('NBP'|'ECB'|'CNB'|'manual'), `rate` (publikovaný/zadaný reťazec), `amount`, `direction`, `validFor`, `tableNo`, `dateBasis`, `dayRule`, `anchorDate`, `entityCurrency`, `invoiceCurrency`, `manual` (bool), `fetched` (?array{source,rate,amount,valid_for,table_no}). Konštruktory: `static fromRate(RateQuote $q, string $dateBasis, string $dayRule, string $anchorDate, string $entityCurrency, string $invoiceCurrency): self`, `static manual(string $rate, string $validFor, string $direction, string $dateBasis, string $dayRule, string $anchorDate, string $entityCurrency, string $invoiceCurrency, ?RateQuote $fetched): self`. Metóda `core(): array` vráti deterministické pole pre snapshot `fx` s kľúčmi v pevnom poradí: `source, manual, rate, rate_display, amount, direction, valid_for, table_no, date_basis, day_rule, anchor_date, entity_currency, invoice_currency, fetched` (`rate` = `bcadd($rate, '0', 8)`, `rate_display` = publikovaný reťazec). Žiadny čas sťahovania (token by driftoval). Metóda `toRateQuote(): ?RateQuote` vráti pôvodný `RateQuote` pre stiahnutý kurz a `null` pre ručný (použije 08-07 na uloženie pôvodne stiahnutého kurzu).
- `final class FxConverter`: `static convert(string $total, string $rate, int $amount, string $direction): string` — `multiply`: `bcdiv(bcmul($total, $rate, 10), (string) $amount, 12)`; `divide`: `bcdiv(bcmul($total, (string) $amount, 2), $rate, 12)`; potom `bcround(..., 2, RoundingMode::HalfAwayFromZero)` a kontrola cez `Money::of` (OverflowException nad MAX). Neplatný vstup → `InvalidArgumentException`.
- `final class FxBoundDate`: `static anchor(string $dateBasis, string $issueDate, string $deliveryDate): string` ('delivery_date'|'issue_date'), `static bound(string $dayRule, string $anchor): string` ('previous_business_day' → anchor − 1 deň, 'on_or_before' → anchor). Neznáma hodnota → `InvalidArgumentException`. Iba kalendárna aritmetika `DateTimeImmutable` (bez sviatkov, D-06).
- `final class FxFormat`: `static rate(string $published, string $language): string` (sk/pl/cs: '.'→',', en: ponechá '.', bez oddeľovača tisícov, koncové nuly zachované); `static parts(array $fx): array{amount: int, base: string, quote: string}` (multiply: base = invoice_currency, quote = entity_currency; divide: base = entity_currency, quote = invoice_currency, amount = 1); `static expression(array $fx, string $language): string` → '1 EUR = 4,2512 PLN' (číta `rate_display`, inak `rate`); `static sourceLabel(string $source): string` ('CNB' → 'ČNB', inak bez zmeny). `$fx` je tvar `FxQuote::core()`.
</interfaces>
