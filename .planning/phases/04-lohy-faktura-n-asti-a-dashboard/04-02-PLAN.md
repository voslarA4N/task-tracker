<interfaces>
`Money` (existuje): `Money::of(string)`, `timesHours(string)`, `toDecimalString()`, regex hodín `^-?\d{1,5}(\.\d{1,2})?$`. `Clock::now(): DateTimeImmutable`, `Clock::today(): string`, služba `service('clock')`, testy `FrozenClock('2026-10-25T10:00:00+02:00')`.

PHPStan pravidlo (`ForbiddenCallsRule`): zakazuje float (`(float)`, float literály, operátor `/`, `round`, `number_format`, `floor`, ...), čas mimo `Clock` (`new DateTime*`, `date()`, ...) a `bc*` mimo `BC_ALLOWED_FILES`. Delenie celých čísel len cez `intdiv()`.

`App\Libraries\Platform\Hours` (final, statické metódy, všetky vstupy aj výstupy string so scale 2):
- `of(string $raw): string` — trim, odstráni medzery a NBSP, čiarku nahradí bodkou, regex `^\d{1,5}(\.\d{1,2})?$` s `/D`, vráti `bcadd(x, '0', 2)`; inak `InvalidArgumentException`. Nuly prijme (`'0'` → `'0.00'`), kladnosť kontroluje volajúci.
- `plus(string $a, string $b): string`, `minus(string $a, string $b): string`, `compare(string $a, string $b): int`, `isPositive(string $h): bool`.
- `remaining(string $quoted, string $allocated): string` — `quoted − allocated`, ak je výsledok záporný, `'0.00'`.
- `delta(string $allocated, string $quoted): string` — `allocated − quoted` so znamienkom (môže byť záporné).
- `percentOf(string $part, string $total, int $step = 5): int` — celé percento zaokrúhlené half-up na násobok `$step`, orezané na 0..100; `$total = '0.00'` → 0. Pre triedy šírky segmentov `.work-progress` (UI-SPEC, bez inline style).
- `format(string $hours, string $locale): string` — desatinná čiarka pre `sk`/`cs`/`pl`, bodka pre `en`; koncové nuly zlomku sa vypúšťajú (`'40.00'` → `40`, `'8.50'` → `8,5`, `'8.25'` → `8,25`); bez jednotky (jednotku „h“ pridá view cez `lang()`).
- `formatSigned(string $delta, string $locale): string` — `'6.00'` → `+6`, `'-2.50'` → `−2,5` (U+2212), `'0.00'` → `0`.

`App\Libraries\Platform\MoneyFormat` (final): `static format(string $amount, string $currency, ?string $locale = null): string` — telo presunuté zo `Settings\Clients::formatRate()` bez zmeny logiky (NumberFormatter, celá a desatinná časť zo stringu, symbol pred/za podľa patternu, NBSP), `$locale` predvolene `service('request')->getLocale()`. Záporné sumy so znamienkom mínus pred číslom.

`App\Libraries\Work\BillingMonth` (final, statické, čistá aritmetika `rok*12 + mesiac` cez `intdiv`, žiadne `new DateTime`):
- `parse(string $raw): ?string` — regex `^\d{4}-(0[1-9]|1[0-2])$` s `/D`, inak null.
- `current(?Clock $clock = null): string` — `$clock ?? service('clock')`, `now()->format('Y-m')`.
- `addMonths(string $month, int $n): string`, `next(string $month): string`, `previous(string $month): string`.
- `inRange(string $month, ?Clock $clock = null): bool` — `current − 12 <= month <= current + 24` (UI-SPEC [predpoklad]); `rangeBounds(?Clock): array{min: string, max: string}`.
- `label(string $month, string $locale): string` — „Október 2026“ cez `IntlDateFormatter` s patternom `LLLL y` nad `IntlCalendar` (nie DateTime), prvé písmeno veľké (`mb_strtoupper` prvého znaku).
- `shortLabel(string $month, string $locale): string` — „Okt“ (pattern `LLL`, bez bodky, prvé písmeno veľké).
</interfaces>
