`billing_allocations`: `id bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY`, `task_id bigint NOT NULL REFERENCES tasks(id) ON DELETE RESTRICT`, `hours numeric(7,2) NOT NULL CHECK (hours > 0)`, `billing_month char(7) NOT NULL CHECK (billing_month ~ '^\d{4}-(0[1-9]|1[0-2])$')`, `rate numeric(12,2) NOT NULL CHECK (rate >= 0)`, `amount numeric(12,2) NOT NULL`, `currency char(3) NOT NULL CHECK (currency IN ('EUR','PLN','CZK'))`, `invoice_id bigint NULL` (FK na `invoices` pridá Phase 5), `created_at timestamptz NOT NULL`, `updated_at timestamptz NOT NULL`, `CHECK (amount = round(hours * rate, 2))`. Indexy: `alloc_task_idx (task_id)`, `alloc_unlocked_month_idx (billing_month, task_id) WHERE invoice_id IS NULL`. Granty: `grantUpdateColumns('billing_allocations', ['hours','billing_month','rate','amount','updated_at'])` + `grantDelete('billing_allocations')`. NIKDY `invoice_id`, `task_id`, `currency`.

Funkcia `alloc_guard()` (plpgsql, nie SECURITY DEFINER): ak `OLD.invoice_id IS NOT NULL` → `RAISE EXCEPTION 'allocation % is locked', OLD.id USING ERRCODE = 'integrity_constraint_violation'`; pri DELETE `RETURN OLD`, inak `RETURN NEW`. Trigger `billing_allocations_guard BEFORE UPDATE OR DELETE ON billing_allocations FOR EACH ROW EXECUTE FUNCTION alloc_guard()`.

Súčty `COALESCE(SUM(...) FILTER (WHERE ...), 0)`.
