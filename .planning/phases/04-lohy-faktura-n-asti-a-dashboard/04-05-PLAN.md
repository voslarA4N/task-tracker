- `add(int $taskId, array $values): int` — `Transaction::run`: `SELECT t.id, t.rate, c.currency FROM tasks t JOIN clients c ON c.id = t.client_id WHERE t.id = :id: FOR UPDATE OF t` (null → `InvalidArgumentException`); `rate` = `$values['rate'] ?? $task['rate']` (D-08); `amount = Money::of($rate)->timesHours($hours)->toDecimalString()`; `INSERT INTO billing_allocations (task_id, hours, billing_month, rate, amount, currency, created_at, updated_at) ... RETURNING id`; `record('billing_allocation', $id, 'create', null, $row)` kde `$row` obsahuje `task_id, hours, billing_month, rate, amount, currency`. Nezávisí od stavu úlohy (D-12).
- `update(int $id, array $values): bool` — `Transaction::run`: `SELECT task_id FROM billing_allocations WHERE id = :id:` (null → `InvalidArgumentException`), `SELECT id FROM tasks WHERE id = :task: FOR UPDATE` (poradie zámkov úloha → časť), `SELECT * FROM billing_allocations WHERE id = :id: FOR UPDATE`; nový `amount` cez `Money`; `UPDATE billing_allocations SET hours = :hours:, billing_month = :month:, rate = :rate:, amount = :amount:, updated_at = :now: WHERE id = :id: AND invoice_id IS NULL`; `affectedRows() !== 1` → `AllocationLocked($id)`; ak sa nič nezmenilo, nevolá UPDATE a vráti false; inak `recordChange('billing_allocation', $id, 'update', $before, $after)`. Presun do iného mesiaca = zmena `billing_month` tou istou metódou.
- `delete(int $id): void` — rovnaké poradie zámkov; `DELETE FROM billing_allocations WHERE id = :id: AND invoice_id IS NULL`; `affectedRows() !== 1` → `AllocationLocked($id)`; `record('billing_allocation', $id, 'delete', $before, null)`.
- `find(int $id): ?array` (stringy pre `hours`, `rate`, `amount`, `invoice_id` int|null, `task_id` int), `listForTask(int $taskId): list<array>` zoradené `billing_month, id`.
