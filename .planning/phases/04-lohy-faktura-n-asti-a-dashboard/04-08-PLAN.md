Nové metódy `TaskService`:
- `remainingHours(int $id): string` — `hours − SUM(časti)` cez `Hours::remaining` (nikdy pod 0); bez zámku, pre predvyplnenie panelu.
- `markDone(int $id, string $month, string $hours): ?int` — `Transaction::run`: `SELECT * FROM tasks WHERE id = :id: FOR UPDATE` (null → `InvalidArgumentException`); `status === 'done'` → `TaskRejected('already_done')`; `UPDATE tasks SET status = 'done', done_at = :now:, updated_at = :now: WHERE id = :id: AND status = 'in_progress'` + `affectedRows() === 1` (inak `TaskRejected('already_done')`); ak `Hours::isPositive($hours)` → `(new AllocationService($this->db, $this->audit))->add($id, ['hours' => $hours, 'billing_month' => $month])` (sadzba z úlohy, D-08) a vráti id časti, inak null; `record('task', $id, 'mark_done', ['status' => 'in_progress', 'done_at' => null], ['status' => 'done', 'done_at' => $now, 'allocation_id' => $aid, 'billing_month' => $month, 'hours' => $hours])`. Hodnoty `month` a `hours` sú už normalizované volajúcim (`AllocationInput::validate(..., true)`).
- `reopen(int $id): void` — `FOR UPDATE`; `status !== 'done'` → `TaskRejected('not_done')`; `UPDATE tasks SET status = 'in_progress', done_at = NULL, updated_at = :now: WHERE id = :id: AND status = 'done'`; časti sa nemenia; `record('task', $id, 'reopen', ['status' => 'done', 'done_at' => ...], ['status' => 'in_progress', 'done_at' => null])`.
</interfaces>
