## Pattern Assignments

### Snapshot client name: SQL fragment (all read-path files)

**Reference:** `app/Libraries/Export/YearArchive.php:47`
```php
coalesce(f.snapshot->'client'->>'name', '') AS client_name
```
**Target form** (D-01 plus NULLIF from RESEARCH so an empty snapshot name also falls back):
```sql
COALESCE(NULLIF(<inv>.snapshot->'client'->>'name', ''), c.name) AS client_name
```
Optional helper `ClientNameSql::snapshotName(string $invoiceAlias = 'i', string $clientAlias = 'c')`: whitelist aliases (`i`, `f`, `c`) only, never request input. Existing `JOIN clients c` stays everywhere (needed for the fallback).

'SELECT i.id, ..., i.created_at, c.name AS client_name, ...

Change `c.name AS client_name` to `COALESCE(NULLIF(f.snapshot->\'client\'->>\'name\',\'\'), c.name) AS client_name`.

### `AccountantBundle.php` (file-I/O, D-07)

Current structure (`:63-118`): `tempnam` -> `try { $zip = new ZipArchive(); open(...) !== true -> throw; loop addFromString (BundleRejected / DocumentIntegrityError); if (! $zip->close()) throw; file_get_contents } finally { if (is_file($tmp)) unlink($tmp); }`.
Fix (RESEARCH, verified repro): declare `$zip = new ZipArchive(); $opened = false; $closed = false;` before `try`; set `$opened = true` after a successful `open`, `$closed = true` after a successful `close()`; in `finally`:
```php
if ($opened && ! $closed) {
    $zip->unchangeAll();   // otherwise libzip re-creates $tmp on destruct
    @$zip->close();
}
if (is_file($tmp)) { unlink($tmp); }
```
Do not use `ZipArchive::closeToString` (not in this build). Unlinking while open is the bug.
