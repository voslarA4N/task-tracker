## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| browser -> InvoiceQueries (`/invoices?sort=&dir=`) | untrusted query string selects the ORDER BY column and direction | sort key (whitelisted string) |
| DB snapshot jsonb -> HTML/CSV/XLSX | user-entered client name from issued-document snapshot rendered in views and exports | client name (PII, low) |
| controller -> ReportCalculator / BundleSelector | entity id and validated ReportPeriod bound as SQL parameters | ints, `YYYY-MM-DD` dates |
| browser -> Payments / InvoiceDelivery (`/invoices/(:num)/...`) | invoice id from URL route | int id |
| browser -> Reports / Accountant (`period`, `year`, `from`, `to`, `entity`) | untrusted query strings | month/year strings |
| PHP process -> `writable/exports` (0700) | temporary ZIP with copies of issued invoice PDFs | client PII, amounts |
| tests -> `writable/archive`, `sys_get_temp_dir()` | test artefacts on disk | test data |
| server -> browser (CSP) | views and versioned static CSS/JS under strict CSP | HTML/CSS |
| owner UAT | staging vs production environment | live business data |

## Informational Notes (non-blocking)

- ClientNameSql's InvalidArgumentException branch has no dedicated unit test. The whitelist exists in code and all call sites pass literals, so T-12.1-01 is closed, but a regression test would pin it.
- `testIntegrityFailureLeavesNoFile` (integration AccountantBundleTest.php:222) still snapshots `exports/zip*`, not `exports/*`. That is equivalent today because `tempnam($dir, 'zip')` is the only writer. The close-failure tests use `exports/*` as declared in T-12.1-09-02.
- `DateBasisTest::removeArchive()` deletes `WRITEPATH/archive` entirely. That is acceptable in the test container, but do not run it against a writable directory with real archives.
