- `final class App\Libraries\Invoicing\ClientNameSql`
- `public static function snapshotName(string $invoiceAlias = 'i', string $clientAlias = 'c'): string`
- returns exactly `COALESCE(NULLIF(<inv>.snapshot->'client'->>'name', ''), <cli>.name)`
- allowed aliases: invoice alias in `['i', 'f']`, client alias in `['c']`; any other value throws `InvalidArgumentException` (never built from request input)
