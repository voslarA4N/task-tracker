# Phase 12.1 - Design Review (D-10..D-13)

Static review of every D-10 screen against UI-SPEC rules R1-R10. Plan 12.1-07 fixes global CSS (`app.css`); plan 12.1-08 fixes view-level findings.

## Method

1. Static pass of `public/assets/css/app.css` and `app/Views/**` against R1-R10 (grep for `nowrap`, `btn-sm`, `<table`, `style="`, off-scale px values, flex rows without `flex-wrap`).
2. Optional headless screenshots of public pages (`/login`, `/offline`) with host `google-chrome --headless=new --window-size=375,812 --screenshot=<abs path>` against the dev stack. Not required, not a dependency.
3. Mandatory owner pass on staging `work-tracker-stage.vostack.dev` (iPhone PWA 375 px and desktop 1280 px, SK/PL/CS), recorded in `12.1-HUMAN-UAT.md`. Prod (`work-tracker.vostack.dev`) is never used for testing.

Matrix values: `static-ok` (static pass found no problem), `finding #N` (see findings table), `owner` (visual confirmation on staging required).
