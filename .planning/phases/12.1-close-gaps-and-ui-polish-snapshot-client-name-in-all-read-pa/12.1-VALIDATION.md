# Phase 12.1 — Validation Strategy

> Per-phase validation contract for feedback sampling during execution.

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | PHPUnit (pin from appstarter), suites unit / integration / feature |
| **Config file** | `phpunit.dist.xml` |
| **Quick run command** | `docker compose exec -T -u www-data php vendor/bin/phpunit <touched test file(s)>` |
| **Full suite command** | `make test`, then `docker compose exec -T -u www-data -e COMPOSER_HOME=/tmp/composer php composer check` |
| **Estimated runtime** | ~30 seconds quick, a few minutes full |

---

## Sampling Rate

- **After every task commit:** run the quick command on the touched test files, plus `composer stan` for PHP changes
- **After every plan wave:** run the full suite command
- **Before `/gsd-verify-work`:** full suite and `composer check` must be green
- **Max feedback latency:** 30 seconds
