# Phase 12.1 - UI Design Contract

> Visual and interaction contract for a POLISH phase over the shipped design system. No new screens, no new components. This document (1) locks the system consolidated from the Phase 02-12 UI-SPECs and the real `public/assets/css/app.css`, (2) defines the rules the design review (D-10..D-13) checks against and that every fix must follow, (3) lists the audited likely defect sources, (4) fixes the review/findings format. Sources: 12.1-CONTEXT.md (D-10..D-13), Phase 02/03/04 UI-SPECs, `app.css` (592 lines), `layouts/app.php`, `layouts/_nav_items.php`, `Language/{sk,pl,cs,en}/App.php`. No user questions asked (owner preference); uncertain items are marked **[discretion]**.

## Spacing Scale

Locked scale (multiples of 4), unchanged since Phase 02/03. Utility mapping (Bootstrap `$spacer` = 16px; `1`=4, `2`=8, `3`=16, `4`=24, `5`=48):

| Token | Value | Bootstrap utility | Usage |
|-------|-------|-------------------|-------|
| xs | 4px | `*-1` | gap between label and value, icon gaps |
| sm | 8px | `*-2` | gap between badges, buttons, tiles; list-row vertical padding in compact rows |
| md | 16px | `*-3` | page side padding, card padding, row padding, field spacing (`mb-3`) |
| lg | 24px | `*-4` | gap between groups/sections, desktop card padding |
| xl | 32px | custom (`mt-4` + `mb-2` or explicit class) | sections of a detail page |
| 2xl | 48px | `*-5` | top offset of empty state, `.auth-wrap` top |
| 3xl | 64px | `--app-tabbar-h` | bottom bar height and bottom reserve of `.app-main` |

Exceptions (existing, keep): 44px minimum touch target; FAB 56x56; progress bars 8px; `.master-row`/`.work-task`/`.inv-row` min-height 48-64px.

**Known off-scale values found in `app.css` that the review must normalise (these are the primary suspects for "missing margins/padding"):**

| Location | Current | Contract value | Why |
|----------|---------|----------------|-----|
| `.app-main` padding | `10px 10px ...` | `16px` sides on mobile (`12px` is NOT allowed) | 10px is off-scale and tighter than every card/row inside it; content touches the screen edge on iPhone. Needs to be coordinated with the `.master-sticky-actions` negative margin below |
| `.app-header` padding | `calc(safe-area + 12px) 14px 10px` | `calc(safe-area + 16px) 16px 8px` (sides must match `.app-main` side padding) | 14/12/10 off-scale; title is not aligned with content edge |
| `.app-card` padding / margin | `12px` / `8px` bottom | `16px` / `16px` bottom (cards stacked with `mb-3`) | cards currently look glued together |
| `.master-sticky-actions` mobile | `margin-left/right: -16px` | must equal the **actual** `.app-main` side padding (16px after fix) | with the current 10px main padding the bar overflows the viewport by 6px each side = likely horizontal scroll at 375px |
| `.app-tabbar` | `font-size: 11px`, no padding | 12px (label token), `padding: 4px` per item, `text-align:center`, `line-height: 1.2`, `min-width:0`, `overflow-wrap:anywhere` | 11px is not in the type scale; 4 items in 375px leave ~94px each, PL/CS labels ("Przeglad", "Zadania", "Faktury", "Wiecej", "Prehled", "Ukoly") fit, but must not touch neighbours |
| `.app-topnav` gap | `8px` + `0 12px` padding | gap 8px, padding `0 16px` | 12px off-scale |
| `.work-month-pick` | `gap: 0` | segmented control: borders joined is intentional; keep, but segments need `padding: 0 8px` and `min-width: 0` so PL/CS labels wrap instead of touching | |
| `.fx-badge` | `margin-left: 8px` | keep 8px but use `ms-2` plus allow badge to wrap to next line (`flex-wrap` on parent) | |
| `.lim-formula`, `.aud-diff` | `padding: 8px 12px` | `8px 16px` | 12px off-scale |
| `.install-hint` | `padding:16px` | keep; verify bottom margin before first card = 16px | |

Rule for every fix: use a token above or the mapped utility. Never introduce 10, 12, 14, 18, 20px paddings/margins.

No new sizes may be added by fixes; where text must be smaller to fit, wrap instead of shrinking.

|------|-------|-------|
| Dominant (60%) | `#f5f6f8` (`--app-bg`) | page background |
| Secondary (30%) | `#ffffff` | header, tab bar, cards, rows, sheets, sticky bars |

Accent reserved for: (1) the single primary button of a screen (`btn-primary`), (2) the FAB `.work-fab`, (3) the active nav item `aria-current="page"`, (4) focus rings, (5) in-body text links, (6) checked radio/checkbox. ## Review Rules (what the design pass checks against)

Every screen in D-10 is checked at **375px** (iPhone) and **>= 1280px**, in **SK, PL, CS** (EN spot check on nav and settings). Each rule is a pass/fail check.

| ID | Rule | Pass criterion |
|----|------|----------------|
| R1 | No horizontal scroll | `document.documentElement.scrollWidth <= 375` at 375px on every screen including open offcanvas sheets and sticky bars. Tables: `.dt-table` blocks are shown only >= 992px (`.dt-only-lg`); any `<table>` visible below 992px (e.g. `settings/_events.php`, `settings/users/index.php`, `settings/audit/_detail.php`) must be wrapped in Bootstrap `table-responsive` (**acceptable only for these dense admin tables**) or replaced by the card pattern `.dt-only-sm` |
| R2 | No overlapping / touching text | Adjacent text elements have >= 8px gap (flex `gap-2`) or wrap onto separate lines. Containers with 2+ children in a row: `d-flex flex-wrap gap-2`, text child `min-width:0` (class `min-w-0` via `.lt-main` pattern or `.text-break`), badge/amount child `flex: 0 0 auto` |
| R3 | Long strings wrap | Headings, button labels, badges, table headers, nav labels, `.nav-pills` items in PL/CS wrap to 2 lines without clipping or overflowing the container. Bootstrap `.badge` is `white-space: nowrap`: where a badge can hold a long PL/CS state label, add `text-wrap` (Bootstrap 5.3 `.text-wrap`) on the badge. `white-space: nowrap` is allowed ONLY for amounts/percentages (`.dt-num`, `.cn-line-amount`, `.lim-pct`) and must never be the only child in a row narrower than the amount |
| R4 | Touch targets | Every interactive element >= 44x44px at 375px: buttons, links in lists, nav items, checkboxes/radios (`.master-check`, `.auth-card .form-check`), `summary`, `.btn-sm` (**`btn-sm` is forbidden on mobile primary paths; if present, add `.btn-touch`**), sort links, close "x" of alerts and hint. Inline text links inside a paragraph are exempt but links alone in an alert get `d-inline-block py-2` (existing pattern in `layouts/app.php`) |
| R5 | Consistent spacing | Page side padding 16px, between cards 16px, between sections 24px, inside a card 16px; use only the scale in "Spacing Scale". Headings: `mb-2` (8px) under `h2`, `mt-4` (24px) above |
| R6 | One-hand use | Primary action reachable in the bottom half: sticky action bar `.master-sticky-actions` above the tab bar on forms, FAB on lists. Sticky bar must not cover the last field (page has bottom padding >= bar height 64px + tab bar 64px) |
| R7 | Fixed layers | Header (sticky, z 10), FAB (z 20), tab bar (fixed), offcanvas sheets and the iOS safe-area: nothing is cut by the notch or home indicator (`env(safe-area-inset-*)` retained). Last element of any page is fully visible above the tab bar |
| R8 | Desktop | >= 992px: tab bar hidden, top nav shown, `.app-main` max 960px (`--wide` 1200px), no stretched full-width forms (forms use `.work-narrow` 720px) |
| R9 | CSP | no new `style=""`, no inline scripts; `grep -rn 'style="' app/Views` (excluding `errors/html/error_exception.php`) returns nothing |
| R10 | Text integrity | Nothing in the review changes wording or numbers except the one new message below; translations keep the 4-language parity (`sk/pl/cs/en`) |

### Prioritised defect hypotheses (check these first)

1. `.app-main` 10px side padding and `.master-sticky-actions` -16px margin mismatch (R1, R5).
2. Header: `.app-header` title block and `.app-topnav` have no gap at 992-1100px with long PL/CS labels (`app-header` is `justify-content: space-between` with no `gap`). Fix: add `gap: 16px` and allow the title to shrink (`min-width: 0`, `.text-break`).
3. Tab bar labels at 11px without padding; adjacent labels touch (R2/R3).
4. `.app-card` 12px padding and 8px stacking margin (R5).
5. Badges (`.st-badge`, `.badge` in `.work-group h2`, `.lt-badge`) are nowrap and sit in a row with a title: long PL/CS text pushes into the title (R2/R3). `.work-group h2` is `display:flex; gap:8px` without `flex-wrap`, add `flex-wrap: wrap`.
6. Rows with title + amount (`.inv-row`, `.cn-line`, `.work-alloc`, `.rpt-switch`) where the amount is nowrap: ensure the text side has `min-width: 0` and the row has `flex-wrap` so the amount drops to its own line below ~360px (R2).
7. `.nav-pills` in `reports/_header.php` and `.work-month-pick` (PL/CS labels) (R3).
8. Unwrapped `<table>` in `settings/_events.php`, `settings/users/index.php`, `settings/audit/_detail.php` (R1).
9. `.lim-row` / `.lim-card`: percentage `white-space: nowrap` next to long entity names (R2).
10. Auth screens: `.auth-code-input` 28px with `letter-spacing: .25em` on 375px with a 16px card padding (R1); `.code-grid` 2 columns of 20px mono codes at narrow widths.
11. Flash alert in `layouts/app.php`: message and link inline with only a space; the link wraps against the message (R2). Fix: put the link on its own line (`d-block mt-2`) on mobile.

Fix order: global layout fixes (items 1-4) first, because they change every screen; then component-level (5-11); re-run the whole matrix once after the global fixes.
