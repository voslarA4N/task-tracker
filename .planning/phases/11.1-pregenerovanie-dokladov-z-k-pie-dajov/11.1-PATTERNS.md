## Pattern Assignments

### `app/Libraries/Invoicing/DocumentStore.php` (mod, service, CRUD bytea)

**Analog:** seba, `app/Libraries/Invoicing/DocumentStore.php` (celý súbor, ~100 riadkov)

**Dnešný `store()`** (lines 28-45), treba ho zmeniť na `INSERT ... SELECT coalesce(max(version),0)+1` a vrátiť `int` (novú verziu). Binárne dáta ostávajú iba cez `decode(:hex:, 'hex')`:
```php
public function store(int $invoiceId, string $kind, RenderedPdf $pdf): void
{
    $this->db->query(
        "INSERT INTO invoice_documents (invoice_id, kind, content, byte_size, sha256, template_version, renderer, created_at)
         VALUES (:i:, :k:, decode(:hex:, 'hex'), :size:, :sha:, :tpl:, :r:, :now:)",
        [ 'i' => $invoiceId, 'k' => $kind, 'hex' => bin2hex($pdf->bytes), 'size' => strlen($pdf->bytes),
          'sha' => $pdf->sha256, 'tpl' => $pdf->templateVersion, 'r' => $pdf->renderer,
          'now' => service('clock')->now()->format('Y-m-d H:i:sP') ],
    );
}
```
Cieľ (RESEARCH Pattern 2): `SELECT :i:, :k:, coalesce(max(version), 0) + 1, decode(:hex:, 'hex'), ... FROM invoice_documents WHERE invoice_id = :i: AND kind = :k: RETURNING version`. Volajúci `InvoiceIssuer.php:255-256` a `CreditNoteIssuer.php:198` ignorujú návratovú hodnotu, takže zmena `void` -> `int` ich nerozbije.

**`read()` / `meta()`** (lines 53-92): pridať `version` do SELECT a `ORDER BY version DESC LIMIT 1`; `StoredDocument` a pole z `meta()` rozšíriť o `version`. Pôvodný tvar:
```php
$row = $this->db->query(
    'SELECT content, sha256, byte_size, template_version, renderer FROM invoice_documents WHERE invoice_id = :i: AND kind = :k:',
    ['i' => $invoiceId, 'k' => $kind],
)->getRowArray();
...
$bytes = pg_unescape_bytea((string) $row['content']);
$sha   = trim((string) $row['sha256']);
self::verify($bytes, $sha);
```
Nové metódy `readVersion(int $invoiceId, string $kind, int $version): ?StoredDocument` (rovnaké telo ako `read`, filter `AND version = :v:`, vždy aj `invoice_id`, IDOR) a `versions(int $invoiceId): list<...>` (bez `content`, `ORDER BY kind, version DESC`). Zachovať `verify()` pri každom čítaní.

**Analógy:** `CreditNoteIssuer.php` (zámok, kontrola, odmietnutie) a `InvoiceIssuer.php` (render, kontrola `templateVersion`, store).

Pre regenerátor: kľúč `hashtext('invoice_documents')`, `SELECT id, origin, type, snapshot, snapshot_schema, created_at FROM invoices WHERE id = :id:`. Ďalšie výskyty vzoru: `ManualSendService.php:214`, `PaymentService.php:275`.

**Render + kontrola šablóny** (`InvoiceIssuer.php` ~lines 240-246):
```php
if ($report->templateVersion !== $snapshot['report_template_version']) {
    throw new RuntimeException('Report renderer returned template ' . $report->templateVersion . ', snapshot requires ' . ... . '.');
}
```
Pri regenerácii porovnávať s `DocumentTemplates::current(...)`, NIKDY so `$snapshot['report_template_version']` (zmrazená stará šablóna, pri 202611001 `rep-1`).

**Registry** (`RendererRegistry.php` lines 22-33): `(new RendererRegistry())->for($tpl)->render($snapshot)`; konštruktor berie `$overrides` pre testy (mapa templateVersion => renderer). Regenerátor prijme `?RendererRegistry` v konštruktore rovnako ako `InvoiceIssuer` (`new InvoiceIssuer($db, null, new RendererRegistry([...]))`, `tests/_support/IssueFixtures.php:104-106`).

**Transakcia + audit:** `Transaction::run($this->db, fn () => ...)` (vzor `FxSettingsService::updateAll`, riadok ~104) a `AuditLogger::record('invoice', $id, 'regenerate_document', $before, $after)` vo vnútri tej istej transakcie. `record()` si sám dopĺňa `user_id`, `occurred_at`, `ip`; názov akcie musí zodpovedať `^[a-z_]{3,40}$` (`AuditLogger.php:20-21`, `:46-52`). Kľúč `sha256` neprejde scrubom (`SENSITIVE_PATTERN`).

**Poradie (RESEARCH diagram):** 1) čítanie riadku bez zámku, 2) policy, 3) render MIMO transakcie, 4) `Transaction::run`: lock, `expected_version == max(version)` inak `stale`, opätovná kontrola lehoty cez `service('clock')->now()` (nie SQL `now()`), `store`, `audit`.
