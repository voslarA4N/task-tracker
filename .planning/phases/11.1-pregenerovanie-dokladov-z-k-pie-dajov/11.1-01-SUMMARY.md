# Phase 11.1 Plan 01: Document versions foundation Summary

**Versioned invoice_documents (UNIQUE per invoice/kind/version, gapless trigger), document_settings with 72 h default, and DocumentStore/BundleSelector that always read the highest version.**

## Accomplishments
- Migration adds `version` (existing rows = 1, no UPDATE), swaps the UNIQUE constraint, adds gapless trigger and `document_settings` (id=1 CHECK, 0..8760, app_rw UPDATE only).
- `DocumentStore`: `store()` returns new version; `read`/`meta` highest; new `readVersion` (scoped by invoice and kind) and `versions` (no content); `StoredDocument::$version`.
- `BundleSelector` uses LATERAL so a regenerated invoice appears once with latest byte_size. No other direct `invoice_documents` readers exist in `app/`.
- Tests: schema, gapless/duplicate, settings guards, immutability of v1 after v2, read tests (incl. mailer attachment uses v2), bundle integration and feature tests.
