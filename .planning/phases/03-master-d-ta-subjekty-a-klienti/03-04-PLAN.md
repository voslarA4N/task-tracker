Nové:
- `App\Libraries\Master\VersionRejected extends RuntimeException` s `public readonly string $reason` (`duplicate_date` | `no_change` | `out_of_range`) a statickými továrňami `duplicateDate()`, `noChange()`, `outOfRange()`.
- `EntityService::newVersion(int $entityId, string $validFrom, array $version): int` — `$version` už normalizovaná a validovaná; overí: subjekt existuje (ak subjekt neexistuje, vyhodí `InvalidArgumentException` (controller vráti 404 ešte pred volaním služby)), `validFrom` je v rozsahu `entities.active_from` až `today + 366 dní` (inak `outOfRange`), `SELECT 1 FROM entity_versions WHERE entity_id = :e: AND valid_from = :d:` (inak `duplicateDate`), `VersionDiff::changedFields(atDate(entityId, validFrom), $version)` nie je prázdne (inak `noChange`). V transakcii (vzor `AccountRecovery`) `INSERT ... RETURNING id` s `created_by`, potom `AuditLogger::record('entity_version', $id, 'create', $before, $after)`, kde `[$before, $after] = AuditLogger::diff(predchádzajúca verzia obmedzená na VERSION_FIELDS, nová verzia)` a do `$after` sa pridá `valid_from` a `entity_id`. `DatabaseException` s porušením unikátu (súbeh) zachytiť **mimo** transakcie a preložiť na `duplicateDate()` (RESEARCH Pattern 2, bod 3).
- `EntityVersionResolver::history(int $entityId, string $today): list<array{id: int, valid_from: string, values: array<string, ?string>, changed: list<string>, is_current: bool, is_future: bool}>` — od najnovšej; `changed` = `VersionDiff::changedFields(staršia, táto)` (pre prvú verziu `[]`); `is_current` = najvyššia `valid_from <= today`; `is_future` = `valid_from > today`.
- `EntityVersionResolver::nextAfter(int $entityId, string $date): ?array` — najbližšia verzia s `valid_from > date`.
- `EntityVersionResolver::find(int $entityId, int $versionId): ?array` — verzia iba ak patrí subjektu (IDOR).
- `App\Libraries\Master\VersionDiff::changedFields(?array $older, array $newer): list<string>` — porovnáva iba `EntityInput::VERSION_FIELDS`, `null` a `''` sú rovnaké, inak striktne ako string; `older = null` → `[]`.

Routy (do `app/Config/Routes/entities.php`): `GET settings/entities/(:num)/versions/new` → `Settings\EntityVersions::newForm/$1`, `GET settings/entities/(:num)/versions/notice` → `::notice/$1`, `POST settings/entities/(:num)/versions` → `::create/$1`.
