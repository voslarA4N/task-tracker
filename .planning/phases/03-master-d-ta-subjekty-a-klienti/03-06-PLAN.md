## Phase Goal

**As a** vlastník (živnostník-programátor), **I want to** spravovať svoje subjekty (s verziami údajov, bankovými účtami a nemennou krajinou a menou) a klientov, **so that** všetko, čo neskôr vstúpi do kópie údajov faktúry, je pripravené a každá zmena je zaznamenaná v denníku zmien.

</objective>

Nové:
- `EntityInput::BASE_UPDATE_FIELDS = ['name_internal', 'active_from', 'active_to']`; `static baseUpdateFromPost(IncomingRequest $r): array<string, string>`; `static validateBaseUpdate(array $v, string $firstValidFrom, string $today): array<string, string>` — `name_internal` 1-100; `active_from` platný dátum, rozsah 2000-01-01 až dnes + 366 a **nie skôr** ako `$firstValidFrom` (najskoršia verzia), inak chyba `Entities.errorActiveFromBeforeFirstVersion` s dátumom; `active_to` prázdne alebo >= `active_from`.
- `EntityInput::IMMUTABLE_KEYS = ['country', 'currency']` a `static hasImmutableKeys(IncomingRequest $r): bool` (true, ak POST obsahuje ktorýkoľvek z kľúčov, aj prázdny).
- `EntityService::updateBase(int $id, array $values): bool` — `UPDATE entities SET name_internal = :n:, active_from = :f:, active_to = :t:, updated_at = :now: WHERE id = :id:` (iba stĺpce z grantu), audit `recordChange('entity', $id, 'update', before, after)` v tej istej transakcii, vráti či nastala zmena.
- `EntityService::end(int $id, string $activeTo): void` — overí `activeTo >= active_from` (inak `InvalidArgumentException`), `UPDATE entities SET active_to, updated_at`, audit `record('entity', $id, 'end', ['active_to' => staré], ['active_to' => nové])`.
- Routy: `GET settings/entities/(:num)/edit` → `Entities::edit/$1`, `POST settings/entities/(:num)` → `Entities::update/$1`, `POST settings/entities/(:num)/end` → `Entities::end/$1`.

Odchýlka od textu UI-SPEC 3a (zdôvodnenie): UI-SPEC píše, že „Aktívny od“ nesmie byť **neskôr** ako prvá verzia. Pri takom pravidle by posun „Aktívny od“ na skorší dátum vytvoril obdobie bez verzie (`EntityVersionResolver::atDate` by hodil `VersionNotFound`). Plán preto uplatňuje pravidlo z 03-RESEARCH Pattern 2 bod 1 (A3): „Aktívny od“ nesmie byť **skôr** ako „Platné od“ prvej verzie. Text chyby: „Dátum „Aktívny od“ nemôže byť skôr ako začiatok platnosti prvej verzie ({0}).“
