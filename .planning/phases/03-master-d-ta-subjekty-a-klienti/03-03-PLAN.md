`App\Libraries\Master\EntityDirectory` (konštruktor `?BaseConnection $db = null`):
- `listAll(string $today): list<array{id: int, name_internal: string, country: string, currency: string, active_from: string, active_to: ?string, vat_regime: string, status: string}>` — **jeden** SQL dotaz: `entities` + `LEFT JOIN LATERAL` na verziu platnú k `:today:` (ak neexistuje, najskoršia), `status` v PHP: `prepared` ak `active_from > today`, `ended` ak `active_to < today`, inak `active`. Poradie: `active` (active_from DESC, id DESC), potom `prepared` (active_from ASC), potom `ended` (active_to DESC).
- `forSelect(string $today): list<array{id: int, name_internal: string, country: string, currency: string, ended: bool}>` — všetky subjekty bez výnimky (ENT-04), `ended = active_to IS NOT NULL AND active_to < today`, zoradené `name_internal`.
- `activeAt(string $date): list<array{id: int, name_internal: string, country: string, currency: string}>` — `active_from <= :d: AND (active_to IS NULL OR active_to >= :d:)` `ORDER BY active_from DESC, id DESC`; prvý prvok = predvyplnený subjekt pre novú faktúru (Phase 5).
- Dátum `today` vždy z `service('clock')->today()` vo volajúcom, nikdy `CURRENT_DATE`.

Route: `GET settings/entities` → `Settings\Entities::index` (pridať do `app/Config/Routes/entities.php` pred `(:num)`).
</interfaces>
