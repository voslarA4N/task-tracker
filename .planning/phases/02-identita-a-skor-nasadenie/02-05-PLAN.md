- `App\Libraries\Auth\SecurityNotifier::notify(string $kind, string $email, string $locale, array $context = []): void`
  - `$kind` ∈ konštanty `SecurityNotifier::PASSWORD_CHANGED = 'password_changed'`, `PASSWORD_RESET = 'password_reset'`, `TOTP_RESET = 'totp_reset'`, `BACKUP_CODES_REGENERATED = 'backup_codes_regenerated'`, `DEVICE_TRUSTED = 'device_trusted'`, `ACCOUNT_LOCKED = 'account_locked'`; iný druh → `InvalidArgumentException`

- `Config\Email::$transport` (`'smtp'|'log'`), env `email.transport`
