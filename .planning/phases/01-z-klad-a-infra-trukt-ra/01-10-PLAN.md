  <action>
`.github/workflows/ci.yml` (D-05): `name: ci`, `on: push` a `pull_request`, `permissions: contents: read`, `concurrency` podľa `github.ref` s `cancel-in-progress: true`. Job `check` na `ubuntu-latest`, `timeout-minutes: 20`, service `postgres` (`image: postgres:18-alpine`, `env: POSTGRES_PASSWORD: ci-superuser`, `ports: ['5432:5432']`, health-cmd `pg_isready -U postgres`). Kroky:
1. `actions/checkout` (najnovší major, napr. `@v7`; ak neexistuje, `@v4`, overené pri písaní);
2. kontrola tajomstiev: `git ls-files | grep -E '(^|/)\.env$|\.pem$|^docker/certs/'` → ak niečo nájde, `exit 1`;
3. `docker build --target dev -t task-tracker-php:ci .` a `docker build --target prod -t task-tracker-php:prod .` (NFR-07, oba z jedného Dockerfile);
4. provisioning pre `task_tracker` a `task_tracker_test` cez `docker run --rm --network host -v "$PWD/docker/postgres:/p:ro" -e PGPASSWORD=ci-superuser postgres:18-alpine psql -h 127.0.0.1 -U postgres -v ON_ERROR_STOP=1 -v owner_pw=ci-owner -v rw_pw=ci-rw -v dbname=<db> -f /p/provision.sql` (klient PG 18 = server, service container nevie mountovať súbory z repa);
5. `.env` pre CI: `cp .env.example .env` a `sed` nastaví `CI_ENVIRONMENT = testing`, všetky `database.*.hostname = 127.0.0.1`, heslá `ci-owner`/`ci-rw` podľa roly (nie skutočné tajomstvá, len pre efemérnu CI DB);
6. `docker run --rm --network host -e CI=true -v "$PWD:/var/www/html" -w /var/www/html task-tracker-php:ci sh -c 'composer install --no-interaction --prefer-dist && composer test:migrate && composer check'`; `-e CI=true` je povinné: `MpdfSpikeTest` (01-06) pri `CI` iba zaznamená čas PDF a nezlyhá na limite 2 s na zdieľanom runneri (`%PDF` a diakritika sa overujú vždy; tvrdý limit 2 s stráži lokálny `make spike-pdf` a Task 3);
7. preload: `docker run --rm task-tracker-php:prod php -d opcache.enable_cli=1 -d opcache.preload=/var/www/html/preload.php -d opcache.preload_user=www-data -r 'echo 1;'` a výstup musí byť `1`.
Žiadne tajomstvá v secrets nie sú potrebné. Cache Composer-a cez `actions/cache` na `~/.cache/composer` je voliteľná (ak ju pridáš, mount do kontajnera `-v ~/.cache/composer:/root/.cache/composer`).

Lokálne prehratie (D-05, push robí vlastník): spusti kroky 3–7 lokálne s dočasným kontajnerom `docker run -d --name tt-ci-pg -e POSTGRES_PASSWORD=ci-superuser -p 127.0.0.1:55432:5432 postgres:18-alpine` (port 55432, aby nekolidoval s dev DB), s `.env` vytvoreným do dočasného adresára (scratch kópia repa cez `git worktree add` alebo `git archive`, aby sa neprepísal dev `.env`), a potom kontajner aj kópiu zmaž. Výsledok zapíš do SUMMARY. Syntax YAML over oficiálnym obrazom Ruby: `docker run --rm -v "$PWD:/w" -w /w ruby:3-alpine ruby -ryaml -e 'YAML.load_file(".github/workflows/ci.yml")'` (exit 0).
  </action>
