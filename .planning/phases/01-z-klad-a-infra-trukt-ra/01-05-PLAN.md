## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| aplikácia (app_rw) → PostgreSQL | každý SQL príkaz aplikácie, aj pri chybe alebo SQL injection |
| migrácie (app_owner) → schéma | jediná cesta zmeny schémy |
| host skripty → DB superuser | reset a provisioning cez lokálny socket v kontajneri |
