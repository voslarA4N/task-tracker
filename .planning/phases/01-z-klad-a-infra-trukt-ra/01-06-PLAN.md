`scripts/spikes/mpdf-fpm.sh` (POSIX sh, beží v kontajneri php, dev target má `cgi-fcgi` z balíka `fcgi`): zavolá FPM priamo cez FastCGI bez nginx a bez CI4 routy: `SCRIPT_FILENAME=/var/www/html/scripts/spikes/mpdf.php REQUEST_METHOD=GET QUERY_STRING=cold=1 cgi-fcgi -bind -connect 127.0.0.1:9000` (prvý beh cold), potom rovnako bez `QUERY_STRING` (warm); z výstupu odreže HTTP hlavičky (všetko po prvom prázdnom riadku) a vypíše dva JSON objekty, každý na samostatnom riadku s prefixom `FPM-COLD ` a `FPM-WARM `. Skript `mpdf.php` z Task 1 už rozpoznáva `$_GET['cold']` pod FPM (ak nie, oprav to v rámci Task 1 a uveď v SUMMARY). Ide len o dev meranie; skript nie je dostupný cez nginx (nginx posiela do FPM iba `/index.php`, plán 01-02).

`tests/integration/MpdfSpikeTest.php` (`Tests\Integration\MpdfSpikeTest extends CIUnitTestCase`, bez DB): test `testColdRunUnderTwoSeconds` a `testWarmRunUnderTwoSeconds` spustia `php scripts/spikes/mpdf.php [--cold]` ako podproces cez `proc_open` (izoluje E_ALL handler od PHPUnit), parsujú JSON (`JSON_THROW_ON_ERROR`) a overia `pdf_bytes > 0`, `str_starts_with(php_version, '8.5')` a `elapsed_ms < 2000`; časový limit sa vynucuje iba lokálne: ak je nastavená premenná prostredia `CI` (`getenv('CI')` neprázdne, GitHub Actions ju nastavuje a 01-10 ju odovzdá do kontajnera), test namiesto tvrdého `assertLessThan` zapíše nameraný čas cez `fwrite(STDERR, …)` a pri prekročení 2000 ms vypíše varovanie, ale nezlyhá (zdieľané runnery majú nestabilný výkon; `%PDF`, `pdf_bytes`, verzia PHP a diakritika sa overujú vždy); `testPdfContainsDiacritics` overí, že súbor začína `%PDF` a že `pdftotext <pdf> -` obsahuje `łńěťžô` (ak `pdftotext` nie je dostupný, `markTestSkipped` s dôvodom). Počet deprecations test neblokuje (vendor kód), ale zapíše ho cez `fwrite(STDERR, …)` a SUMMARY ho uvedie spolu so zoznamom.

Podproces v teste dedí používateľa PHPUnit; test sa preto spúšťa ako `www-data` (`docker compose exec -T -u www-data php vendor/bin/phpunit …`), aby nevznikli root-owned súbory v `writable/mpdf/spike`, ktoré by zablokovali FPM beh. Spusti `docker compose exec -T -u www-data php sh scripts/spikes/mpdf-fpm.sh` a test. Do SUMMARY zapíš tabuľku: CLI cold/warm, FPM cold/warm × `elapsed_ms`, `peak_memory_mb`, `deprecations_count`, `pdf_bytes`, a odporúčanie (memory_limit pre PDF požiadavky, prípadné potlačenie vendor deprecations v prod). Plán 01-10 tieto čísla prenesie do PROJECT.md.
