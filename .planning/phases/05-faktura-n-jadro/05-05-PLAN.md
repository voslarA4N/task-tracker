`App\Libraries\Invoicing\InvoiceGuards` (konštruktor `?BaseConnection $db = null`):
- `assertCurrency(array $entity, string $invoiceCurrency): void` — `trim(entity.currency) !== $invoiceCurrency` → `IssueRejected('currency_mismatch', ['currency' => ..., 'entity_currency' => ...])`.
- `assertEntityActive(array $entity, string $issueDate): void` — `active_from <= issueDate` a (`active_to IS NULL` alebo `>= issueDate`), inak `IssueRejected('entity_inactive', ['date' => $issueDate])`.
- `lastIssue(int $seriesId): ?array{number: string, issue_date: string}` — `SELECT number, issue_date FROM invoices WHERE series_id = :s: AND origin = 'issued' ORDER BY issue_date DESC, id DESC LIMIT 1`.
- `backdate(int $seriesId, string $issueDate): ?array{number: string, issue_date: string}` — vráti poslednú faktúru, ak `issueDate < last.issue_date`, inak null.

V `InvoiceIssuer::issue` (miesto `// 05-05: guards`): po kroku 6 `assertEntityActive($entity, $cmd->issueDate)` a `assertCurrency($entity, $snapshot['currency'])`; po kroku 7 (zámok radu) `backdate($seriesId, $cmd->issueDate)` ≠ null a `! $cmd->confirmBackdate` → `IssueRejected('backdate_unconfirmed', ['last_number' => ..., 'last_date' => ...])`.

`App\Libraries\Invoicing\Draft` (final readonly): `int $clientId`, `string $month`, `?int $entityId`, `string $issueDate`, `string $deliveryDate`, `string $dueDate`, `list<array> $lines`, `string $total`, `string $hours`, `int $lineCount`, `?string $currency`, `list<int> $partIds`, `?string $previewToken`, `?array $snapshot` (bez čísla), `?array $backdate` (`number`, `issue_date`), `bool $hasLockedInMonth`, `list<array{reason: string, context: array}> $errors`, `list<array{id: int, name_internal: string, country: string, currency: string}> $entities` (aktívne k dátumu vystavenia), `bool $canIssue` (= riadky > 0, žiadne chyby, entita vybraná).

`App\Libraries\Invoicing\InvoiceDraftService` (konštruktor `?BaseConnection $db = null`, ostatné služby na tom istom spojení):
- `defaultMonth(int $clientId): string` — `SELECT min(a.billing_month) FROM billing_allocations a JOIN tasks t ON t.id = a.task_id WHERE t.client_id = :c: AND a.invoice_id IS NULL`, inak `BillingMonth::previous(BillingMonth::current())`.
- `draft(int $clientId, string $month, ?int $entityId, ?string $issueDate, ?string $deliveryDate, ?string $dueDate): Draft` — iba čítanie, bez transakcie a bez zámkov. `issueDate` predvolene `service('clock')->today()`; `deliveryDate` predvolene posledný deň mesiaca; zoznam subjektov `EntityDirectory::activeAt($issueDate)`; vybraný subjekt = `$entityId`, ak je v zozname, inak prvý zo zoznamu, inak null s chybou `entity_inactive`; `dueDate` predvolene `issueDate + (client.due_days ?? verzia subjektu k issueDate .due_days)` dní; riadky `InvoiceParts::unlocked` + `InvoiceCalculator::compute($parts, $vatCode)` (kód DPH z profilu, ak sa dá určiť, inak null); `IssueRejected` z calculatora (`mixed_currency`, `amount_mismatch`) aj z `SnapshotBuilder::build` (`legal_text_missing`, `vat_code_missing`, `no_bank_account`, `version_not_found`) a `assertCurrency` sa zachytia do `errors` (sú to doménové výnimky pred akýmkoľvek zápisom, nie `DatabaseException`); `previewToken` = `InvoiceCalculator::previewToken(...)` pri neprázdnych riadkoch; `backdate` cez `InvoiceGuards::backdate` pre rad `invoice` subjektu; `hasLockedInMonth` = `InvoiceParts::hasLocked`. Neexistujúci klient → `InvalidArgumentException`.

`SeriesService::isFormatLocked(int $seriesId): bool` = `SELECT EXISTS (SELECT 1 FROM invoices WHERE series_id = :s:) AS locked` (docblock bez textu „V Phase 3 este neexistuju“).
