- kroky (`STEP`): `restore` (`restic restore latest --tag db --host work-tracker --target "$TMP"`, nájsť `task_tracker.dump`, `manifest.txt`, `.sha256` cez `find`), `checksum` (`sha256sum -c`), `createdb` (`docker compose exec -T db createdb -U postgres -O app_owner <db>`), `pg_restore` (`docker compose exec -T db pg_restore -U app_owner --no-owner --exit-on-error -d <db> < dump`), `compare` (rovnaké SQL ako manifest v 12-04 nad obnovenou DB; každý kľúč manifestu okrem `created_at`, `env`, `dump_sha256` musí sedieť, `documents_bad_sha256` = 0; rozdiel vypíše kľúč a obe hodnoty), `dropdb` vždy v `trap` (okrem `RESTORE_KEEP=1`), `rm -rf "$TMP"` vždy.
- výstup úspechu `OK: obnova <snapshot id> <db> rows.invoices=<n> last_invoice_number=<číslo>`; chyba → `notify_fail 'Test obnovy zlyhal' ...` (iba serverový režim) a exit != 0.
- cron (zdokumentuje 12-13): `30 4 1 * * /usr/local/lib/work-tracker-backup/scripts/restore-test.sh >> /var/log/work-tracker-restore-test.log 2>&1`.

`scripts/pull-backups.sh` (WSL, spúšťa vlastník): env `PULL_SSH_TARGET` (predvolene `backuppull@2.31.74.48`), `PULL_SSH_KEY` (predvolene `$HOME/.ssh/work-tracker-backup-pull`), `PULL_DEST` (predvolene `$HOME/backups/work-tracker-restic`); `install -d -m 0700 "$PULL_DEST"`; `rsync -a --partial --exclude '/locks/' -e "ssh -i $PULL_SSH_KEY -o IdentitiesOnly=yes -o BatchMode=yes" "$PULL_SSH_TARGET:" "$PULL_DEST/"` (bez `--delete`: pri zmazaní repozitára na serveri ostane kópia na PC; zmazané balíky po prune na PC zostávajú a sú neškodné); ak je nastavené `RESTIC_PASSWORD_FILE` a `restic` je dostupný, `restic -r "$PULL_DEST" snapshots --compact --no-lock` a `restic -r "$PULL_DEST" check --no-lock`; `OK: pull <dátum> <veľkosť>`.
