<objective>
Čisté výpočtové jadro limitov bez DB: dátumové okná pre tri spôsoby výpočtu (LIM-05), pomerný limit prvého roka, aritmetika prahov a percent bez float (LIM-03) a hodnotový objekt `LimitStatus`, ktorý neskôr prinesie `TurnoverCalculator` (10-02) do nastavení, dashboardu aj predkontroly.

Purpose: Core Value „súčty sa zhodujú všade“ stojí na tom, že dátumová a percentová aritmetika je na jednom mieste a otestovaná na hranách (D-03, D-12, D-17). Dedikovaný TDD plán, lebo ide o čistú logiku s jasným vstupom a výstupom.
Rozhodnutia v rámci voľnosti (zapísať do SUMMARY):
- A3: počet dní pomerného limitu sa obmedzí na 365 (`min(dni, 365)`), základ 365 aj v prestupnom roku (D-03 [overiť] s účtovníčkou).
- A4: rozhodnutie o prahu presným porovnaním; percento na zobrazenie half-up na 1 desatinné miesto (UI-SPEC), hrana 79,96 % je otestovaná.
- D-07 (rolling_12m): `openingYears` = všetky kalendárne roky, do ktorých okno zasahuje (počiatočný obrat sa pripočíta celý, konzervatívne).
- Okno sa vždy počíta z referenčného dátumu (dnes alebo dátum dodania), nie z roka riadku limitu; fallback roka (D-05) mení len výber riadku, nie obdobie.
Output: 4 triedy v `App\Libraries\Reporting`, 2 unit testy.

Nové (namespace `App\Libraries\Reporting`, `declare(strict_types=1)`):

- `final readonly class LimitPeriod`: `__construct(public string $from, public string $to, public array $openingYears, public ?int $proRataDays, public bool $proRataOutsideFirstYear)`; `@param list<int> $openingYears`. `from`/`to` sú `Y-m-d`.

- `final class PeriodResolver`:
  - `public const METHODS = ['calendar_year', 'rolling_12m', 'pro_rata_first_year'];`
  - `public const PRO_RATA_BASE_DAYS = 365;`
  - `public static function resolve(string $method, string $refDate, ?string $activeFrom): LimitPeriod` — `InvalidArgumentException` pri neznámej metóde alebo neplatnom dátume (prísne `!Y-m-d` v UTC, ako `Clock::parseDate`). Rok `Y` = rok `refDate`.
    - `calendar_year`: `Y-01-01` až `Y-12-31`, `openingYears [Y]`, `proRataDays null`, `proRataOutsideFirstYear false`.
    - `rolling_12m`: `first = refDate` → prvý deň mesiaca; `from = first − 11 mesiacov`; `to = posledný deň mesiaca refDate`; dátumy skladať z celých čísel (rok, mesiac) alebo `modify('first day of this month')` pred odpočtom mesiacov (Pitfall 1); `openingYears = range(rok(from), rok(to))`.
    - `pro_rata_first_year`: ak `activeFrom !== null` a `rok(activeFrom) === Y`: `from = activeFrom`, `to = Y-12-31`, `proRataDays = min(počet dní from..to vrátane, 365)`, `proRataOutsideFirstYear false`; inak ako `calendar_year` s `proRataOutsideFirstYear = true`. `openingYears [Y]`.
  - `public static function proRataLimit(string $amount, int $days): string` — `bcround(bcdiv(bcmul($amount, (string) $days, 2), '365', 6), 2, RoundingMode::HalfAwayFromZero)`, výsledok formátovaný na 2 desatinné miesta (`'111780.82'`). `InvalidArgumentException` ak `days < 1` alebo `days > 365`.

- `final class LimitMath` (všetko reťazce, scale explicitný, žiadny float):
  - `public static function percent(string $total, string $limit): string` — `bcround(bcdiv(bcmul($total, '100', 4), $limit, 6), 1, RoundingMode::HalfAwayFromZero)`, výsledok s presne 1 desatinným miestom (`'88.5'`, `'0.0'`, `'112.4'`).
  - `public static function ratio(string $total, string $limit): string` — `bcdiv($total, $limit, 8)` na zoradenie (D-02 prísnejšia hodnota).
  - `public static function reached(string $total, string $limit, int $threshold): bool` — `bccomp(bcmul($total, '100', 4), bcmul((string) $threshold, $limit, 4), 4) >= 0`.
  - `public static function reachedThresholds(string $total, string $limit, array $thresholds): array` — vzostupne zoradený `list<int>` dosiahnutých prahov.
  - `public static function level(string $total, string $limit, array $thresholds): string` — `'crit'` ak dosiahnutý `max($thresholds)`, `'warn'` ak dosiahnutý ktorýkoľvek nižší, inak `'normal'`.
  - `public static function remaining(string $total, string $limit): string` — `max(0, limit − total)` cez `Money`, `'0.00'` pri prekročení.
  - `public static function exceededBy(string $total, string $limit): string` — `max(0, total − limit)` cez `Money`.
  - `public static function formatPercent(string $percent, string $locale): string` — iba zobrazenie čísla bez znaku %: pre `en` vráti vstup (`'88.5'`), pre ostatné jazyky nahradí bodku čiarkou (`'88,5'`); vstup musí vyhovovať `/^-?\d+\.\d$/D`, inak `InvalidArgumentException`. Jediné miesto formátovania percenta pre nastavenia (10-03), dashboard (10-05) aj predkontrolu (10-06).

- `final readonly class LimitStatus` (iba verejné readonly vlastnosti, žiadna logika okrem `isAlert()`):
  `__construct(int $limitId, int $entityId, string $name, string $country, int $limitYear, int $refYear, ?int $fallbackFromYear, string $method, array $thresholds, string $periodFrom, string $periodTo, string $documentTurnover, int $invoiceCount, int $creditNoteCount, string $openingTurnover, array $openingYears, string $total, string $baseLimit, string $limit, ?int $proRataDays, bool $proRataOutsideFirstYear, string $percent, string $ratio, string $remaining, string $exceededBy, string $currency, string $level, ?string $error, bool $isSeed)`;
  `@param list<int> $thresholds`, `@param list<int> $openingYears`; `fallbackFromYear` = požadovaný rok, keď sa použil riadok iného roka (D-05), inak null; `error` je `null` alebo `'currency_mismatch'` (D-11); `public function isAlert(): bool` = `$this->error !== null || $this->level !== 'normal'`.
