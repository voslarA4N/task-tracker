<objective>
Fix the "Viac" (More) menu on desktop. Item titles and hints currently sit side by side with no space between them. The fix stacks the title above the hint.

Root cause: `.more-item` (public/assets/css/app.css, the "Viac a Zabezpecenie" block) is a flex row with `align-items: center`. In app/Views/more/index.php the title text node and the `<span class="d-block small text-body-secondary">` hint become two flex items next to each other, so `d-block` has no effect.

Purpose: The menu must be readable on desktop and stay easy to tap with one hand on iPhone (44px minimum touch target; this project uses 48px).
Output: Updated `.more-item` rule and a regression test.
</objective>

Do NOT rename app.css.
- AppCssScaleTest strips comments, then parses `prop: value` declarations. Spacing values 10/12/14/18/20px are forbidden. Font sizes are limited to 12/16/20/28px. It extends plain `PHPUnit\Framework\TestCase` and reads the file from `dirname(__DIR__, 3) . '/public/assets/css/app.css'`.
- Strict CSP: no inline `style=""` attributes. The view must stay as is; the fix is CSS only.
